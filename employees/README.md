# 🐝 Hivework AI Employees

> **Autonomous Business Roles for Local Agents (Free for Personal Use)**
> Part of the [Hivework](https://github.com/allanindrajith/hivework) ecosystem by Allan Indrajith.

Unlike conversational chat prompts, each **Hivework AI Employee** is a self-contained, autonomous operational package with defined schedules, routines, audit cycles, and measurable KPIs. They run locally on your laptop using your existing coding agents (Antigravity, Claude Code, Cursor, Windsurf, Codex, etc.).

## 🚀 How to Hire an Employee

Use the **`hive-hire`** skill:

```bash
# In your agent session, simply invoke:
"Hire the Web Dev Employee into ~/hivework-employees/web-dev"
```

The `hive-hire` skill will:
1. Copy the employee package into your target folder.
2. Verify all local node routines and run-cycle scripts pass self-tests.
3. Hand over the tailored `INSTALL-PROMPT.md` to initialize your persistent daily schedule.
